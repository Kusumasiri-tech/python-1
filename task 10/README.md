TASK – 10
Problem statement
Calculate each passenger’s fare using distance slabs and class rates, apply a senior discount when eligible, add reservation fees, and calculate the refund if the booking is cancelled.
Objectives
•	Calculate fares based on travel distance and class.
•	Apply a 40% discount for passengers aged 60 or older.
•	Add the reservation fee and calculate the total fare.
•	If cancelled, subtract penalties and display the refund.
Assumptions
•	Each passenger’s class matches an entry in class_rates.
•	A passenger aged 60 or older receives the discount.
•	The cancellation penalty applies to each passenger.
•	Refunds cannot be less than zero.
Algorithm
1.	For each passenger, find the rate for their distance.
2.	Calculate fare using distance and class rate.
3.	Apply the senior discount if eligible, then add the reservation fee.
4.	Display each passenger’s fare and the total.
5.	Ask whether to cancel.
6.	If cancelled, subtract the total cancellation penalties and display the refund.
Testcase
Input:
•	Cancel reservation? yes
Expected output:
Asha: ₹400.00
Ravi: ₹184.00
Total fare: ₹584.00
Cancel reservation? (yes/no): yes
Refund after cancellation penalties: ₹384.00
