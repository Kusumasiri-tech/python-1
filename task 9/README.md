TASK –  9
Problem statement
Calculate each team’s points and goal difference from match results, then rank teams by points, goal difference, and name.
Objectives
•	Award 3 points for a win and 1 point to each team for a draw.
•	Calculate each team’s goal difference.
•	Rank teams using the specified tie-breakers.
Assumptions
•	Each match lists two teams and their goals.
•	Higher points rank first; ties are broken by higher goal difference, then alphabetical team name.
Algorithm
1.	Read each match and initialize team results if needed.
2.	Update both teams’ goal differences.
3.	Award points based on the match result.
4.	Sort teams by points, goal difference, then name.
5.	Print the rankings.
Testcase
Expected output:
1. Lions: 4 points, tie-break value 1
2. Tigers: 3 points, tie-break value 2
3. Eagles: 1 points, tie-break value -3
